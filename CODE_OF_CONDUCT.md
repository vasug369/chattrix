# Code of Conduct

Chattrix adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every project space: issues, pull requests, discussions and reviews.

## In short

**Do:**

- be kind and respectful, including when you disagree
- give and accept feedback on the work, not the person
- take responsibility for mistakes and learn from them
- put the community's wellbeing first

**Do not:**

- harass, insult or demean anyone
- use sexualised language or imagery
- publish someone's private information without permission
- troll, spam or make personal or political attacks

## Reporting

Report unacceptable behaviour privately to the maintainer, [@vasug369](https://github.com/vasug369), through GitHub. Reports are handled promptly and confidentially.

## Enforcement

The maintainer decides on action, following the Covenant's enforcement guidelines:

1. **Correction:** a private warning.
2. **Warning:** a warning with consequences for continued behaviour.
3. **Temporary ban** from project spaces.
4. **Permanent ban** from project spaces.
